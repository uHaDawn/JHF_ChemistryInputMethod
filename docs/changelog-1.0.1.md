# 接化发 · 化学输入法 1.0.1 更新日志

**发布日期**：2026-11-11　｜　**版本号**：1.0.1（versionCode 21）　｜　**基线版本**：1.0.0

本次为修复版本，解决 1.0.0 引入的启动崩溃问题，并去掉候选字界面滑块背景胶囊的阴影。无新功能、无破坏性变更，覆盖安装即可，词库与本地设置保留。

## 一、问题修复

- **启用输入法即崩溃，提示「应用出错了」**：1.0.0 为让剪贴板与键盘共用槽位，在键盘外层加入了 `kbSlot`（FrameLayout），键盘的布局参数类型随之由 `LinearLayout.LayoutParams` 变为 `FrameLayout.LayoutParams`，而键盘几何下发仍按旧类型强转，每次唤起键盘都会抛出 `ClassCastException`，手机与平板、横竖屏均复现。现改为按两者共同的父类 `ViewGroup.MarginLayoutParams` 读写底部外边距，并在取值前做类型判断，启动路径恢复正常，底部间隙撑高槽位与卡片的行为与原先一致。

- **键盘调节的底部拖手回显始终为 0**：调节浮层读取底部间隙时只认 `LinearLayout.LayoutParams`，槽位改造后该判断恒不成立，拖手位置无法反映已保存的底部间隙。同步改为 `MarginLayoutParams` 后，底部间隙可正确回显，拖动、取消与保存行为与 1.0.0 的设计一致。

## 二、优化改进

- **候选字界面滑块背景胶囊去阴影**：「词频 / 单字」分段滑块背后的胶囊底板原由两层叠加绘制，下层深色胶囊整体下移 1dp，露出一条深色边，视觉上近似投影。现改为单层纯色胶囊（浅色 `#C9C9C9`、深色 `#414141`），圆角、配色与滑块滑动动画保持不变。

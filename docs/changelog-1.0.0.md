# 接化发 · 化学输入法 1.0.0 更新日志

**发布日期**：2026-11-09　｜　**版本号**：1.0.0（versionCode 20）　｜　**基线版本**：0.0.10

本次为 1.0.0 正式大版本，versionCode 由 10 升至 20。以下按「新功能」「优化改进」「问题修复」「破坏性变更」四类说明。

## 一、新功能

- **化学方程式自动配平**：化学键盘新增「自动模式」。点击输入区右侧的「+」，输入物质中文名或拼音，候选栏给出物质名称与化学式；选中后生成一个反应物芯片，重复添加齐全后点击底部「发生反应」，键盘直接给出配平结果。输入区顶部显示「已配平」，并提供「撤销」与「确认」两个按钮，确认后方程式上屏。匹配时先按完整反应物组合精确查找；若含离子且未命中，则剔除硫酸根、钠离子、硝酸根等旁观离子，用剩余离子组合输出净离子方程式。内置配平反应库 989 条、离子反应库 594 条，配平在构建期离线完成，运行时只查表。

- **普通中文键盘（全拼 / 双拼 / 九键）**：工具条第 2 个按键新增键盘类型菜单，可在「化学输入」「普通·全拼」「普通·双拼」「普通·九键」之间切换，当前生效项右侧显示蓝色对勾，键盘会记住上次选择。中文输入接入 Rime 内核（librime 1.17.0 + ONNX Runtime 1.28），内置约 40 MB 的 rime-ice 中文词库与 OpenCC 简繁数据，安装后无需联网下载。

- **键盘工具条 8 键**：键盘顶部重做为统一工具条，从左到右依次为品牌圆键、键盘模式、深浅切换、悬浮键盘、键盘调节、剪切板、切换输入法、收起。品牌圆键在字母页点击回到化学键盘首页、长按进入符号页；切换输入法直接唤起系统选择器且键盘不收起。

- **键盘尺寸调节**：点击工具条「调节」进入编辑态，键盘四周出现拖拽条，分别控制上、下、左、右边界，拖动时键盘实时变形。中央提供「重置」「取消」「保存」三个圆形按钮，其中保存后再次唤起键盘仍然生效。

- **本地剪贴板历史**：点击工具条「剪切板」打开全屏历史面板，记录按时间倒序排列，点选卡片即上屏，右侧的 × 可删除单条，最多保留 50 条且仅存本机。复制化学式时同时保留可直接阅读的写法与 LaTeX 源码，便于粘贴到支持公式的编辑器。

- **关于页与第三方许可**：关于页重做为软件交流群、应用文档入口、作者与出品信息、许可与鸣谢四块内容，页面上滑会出现吸顶栏。第三方许可清单以半屏面板呈现，可上拖展开为全屏列表，条目逐条标注版本、作者、许可证类型与项目地址，点击可查看许可证全文。

- **主界面键盘试用**：首页新增「键盘试用输入框」，可直接在应用内唤起键盘试用键位与配平流程，避免在聊天软件中误发内容。

- **全新应用图标**：补充自适应图标与深色变体，覆盖 mdpi 到 xxxhdpi 五档，浅色与深色桌面各取对应图标。

- **数字页与符号页完善**：普通键盘新增 123 数字页，包含 + − × ÷ = % 六个运算符、数字、小数点与斜杠；符号页按常用、中文、英文、其他四类整理，写反应式时可在字母页取元素、符号页取箭头、数字页补上下标。

## 二、优化改进

- **主界面结构重做**：首页改为「应用信息」「通用」「键盘试用输入框」三段式圆角卡片，深浅色同步换肤，去掉旧版散落的外观与布局入口，信息层级更集中。

- **化学键盘键面重绘**：每个字母键统一承载三层信息，中间是主字符，右上角是数字或常用小符号，蓝色标注为化学符号。点按输入主字符，上滑输入角标符号，长按查看全部变体；长按气泡统一为 5 个形态，滑动时当前项高亮，松手输出，滑出气泡区域取消。

- **主题收敛为三态**：外观统一为浅色、深色、跟随系统三态循环，入口在首页「通用 → 浅色模式」和键盘工具条第 3 个按键，两处效果一致。深色改为纯黑底与深灰键面，在 OLED 屏幕上更省电，夜间书写也不刺眼，主题选择会被记住。

- **引导与关于页细节重做**：引导页重排窄屏下的文案与按钮布局，避免文字贴边；关于页补充圆润版面、返回箭头与吸顶栏对齐，深色模式下图标与卡片配色统一。

- **智能联想补全**：上屏沉淀化合物自动追加「↓」，气体追加「↑」，单独元素追加常见离子（如 Fe → Fe²⁺、Fe³⁺），输入 qq 等常见缩写给出对应物质与状态符号；重新输入、空格或删除后联想自动清空。

- **词库与自检**：化学词库 3948 条，含 479 条多读音；运行 `python source/tools/test_matcher.py`，用例与全库抽样自匹配合计 117/117 通过，240 条随机抽样未命中 0 条。

- **工程结构整理**：安装包与调试截图移出版本库，原生库落到 `prebuilt/arm64-v8a/`，补齐 `.gitattributes`、第三方许可清单与 `docs/build-native.md`；使用文档纳入 `docs/user-guide/`，README 与飞书手册口径对齐。

## 三、问题修复

- **进入键盘调节态时输入法整块跳到屏幕上方**：调节浮层由 `MATCH_PARENT` 改为按键盘高度测量，进入编辑态后保持原位置。

- **调节拖动时键盘锁在顶部、纵坐标不跟手，拖动卡顿**：修正触摸坐标换算，拖动位移改为 `postOnAnimation` 按帧合并，同一帧内多个触摸采样点只下发一次。

- **调节单边时左右两侧联动收窄**：取消把单边位移翻倍成对称收窄的换算，四条边可独立拖拽。

- **普通（平铺）键盘按键文字整体消失**：补上新增字号字段 `fsText` 的构造初始化。

- **35dp 候选栏里副标题被裁掉**：候选芯片行内边距由 4dp 收至 2dp，并关闭字体预留。

- **工具栏、符号页、字母页切换时上下抖动**：三处分页内边距统一为 11，切换时三岛纵坐标保持不动。

- **输入被打断后残留字符拼接（26 键双拼 / 九键）**：中断时清空组合状态，重新输入不再与残留字符拼接。

- **九键选词后输入框残留数字串（如「43个」）**：选词后清理数字缓冲；中文模式下打开数字键盘时，按数字不再走 T9 逻辑。

- **Android 12 以下背景模糊动画无法正确取消**：`UiBlur.cancel()` 同时取消低版本路径的动画实例，避免旧回调覆盖新状态。

- **含电荷离子时配平结果不正确或查不到**：重做离子匹配流程，先精确匹配完整组合，未命中再剔除旁观离子求净离子式。

## 四、破坏性变更

- **移除键盘主题配色选择**：AgBr、KMnO₄、CuCl₂、Fe₂O₃ 四套试剂配色与「自动」壁纸取色不再提供，外观只剩浅色、深色、跟随系统三态。升级后旧主题偏好在界面上不再生效，需要重新选择深浅模式。

- **移除平板「键盘布局」设置项**：平铺、悬浮、分离三种布局的选择入口不再保留，键盘形态改由工具条第 4 个按键在「内嵌」与「悬浮」之间切换，旧版「分离」布局不再提供入口。

- **版本号跨越**：由 0.0.10（versionCode 10）直升 1.0.0（versionCode 20）。覆盖安装需与旧包使用同一签名，跨签名升级须先卸载旧版本。

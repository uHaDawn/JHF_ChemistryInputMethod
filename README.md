# 接化发 · 化学输入法

一款面向化学学习与写作场景的 Android 输入法。输入拼音就能打出化学式，上滑输入上下角标，长按取
符号变体，全程离线运行、不申请网络权限。

**📖 [用户使用手册](https://my.feishu.cn/docx/PHNfdxuEYoLYJpx0IXUcMurD6id)** ·
[更新日志](https://my.feishu.cn/docx/Uw3WdDHdeomiZ8xi0EFcf80Y6Cd) · QQ 交流群 `1132293331`


## 它是什么

接化发在普通英文键盘的基础上，把化学写作中最常用的三类内容放到键面上：

- **化学式候选**：输入中文名称的拼音或首字母，直接给出硫酸铜、碳酸钠等化学式
- **符号与角标**：上滑或长按即可输入 ⁰¹²³ / ₀₁₂₃ / ⇌ / ℃ / λ / σ 等符号
- **主题外观**：四套化学试剂配色，支持浅色、深色与跟随系统

如果只用于日常聊天，系统自带输入法已经够用；如果经常写化学式、反应式或实验报告，本输入法可以
减少反复切换符号面板的次数。

## 1 分钟验证

| 试一下 | 应得到 |
|---|---|
| 依次点 `T` `O` `N` `G` | 候选栏出现 `Cu`、`Cu₂(OH)₂CO₃`、`Cu²⁺` 等 |
| 在 `Q` 键上向上滑 | 输入下标 `₁` |
| 长按 `T` 键 | 弹出 `⁵ / ₅ / 5 / ᵀ / ᵗ`，按住滑到目标项松手即输出 |
| 输入 `qq` | 候选 `H₂↑`（气体自动带 ↑） |
| 输入 `dao` | 候选 `²H`（同位素） |

## 键盘使用

### 字母页的三种按法

| 操作 | 结果 |
|---|---|
| 点按字母键 | 输入该字母 |
| 在字母键上向上滑 | 输入键面右下角的化学符号，如 `Q` → `₁`、`A` → `λ`、`V` → `σ` |
| 长按字母键 | 弹出 5 个形态，按住滑动到目标项松手输出，滑过的项会高亮 |

其余功能键：`⇧` 只影响下一个字母大小写；`⌫` 删除光标前一个字符、长按连续删除；空格在拼音候选
状态下提交当前候选；`←` 为回车/确认，随宿主应用表现为换行、搜索或发送。

### 拼｜素：两种输入模式

键盘左下角的「拼｜素」键切换模式，当前模式为实色。

- **拼（拼音模式）**：输入全拼或首字母，候选栏给出化学式，首字母相同的多种物质一起列出

  | 输入 | 候选示例 |
  |---|---|
  | `tansuan` | `H₂CO₃`、`CO₃²⁻` |
  | `lst` | `Fe(ClO₃)₃`、`Cu(ClO₃)₂` |
  | `qq` | `H₂↑` |

- **素（直通模式）**：按字母直接上屏，适合手动拼写化学式
  - 输入 `CuSO4` 时候选栏给出规范化写法 `CuSO₄`；输入 `235U` 得到 `²³⁵U`
  - 长按「拼｜素」可开启「元素自动大小写」：`C` + `u` 自动组成 `Cu`（默认关闭）

### 符号页

符号页按学科用途分为**度量 / 物质 / 反应 / 其他**四类，分类栏在左侧，点击切换右侧网格。

写反应式常用组合：字母页输入元素，符号页取 `⇌` 或 `→`，再补上下标。例如水的电离写成
`H₂O ⇌ H⁺ + OH⁻`。

### 候选栏与底部 ⇌ 条

- **化｜符**：切换字母页与符号页，输入法会记住当前所在页
- **候选输入区**：左侧显示正在输入的拼音，右侧列出候选化学式，点选上屏
- **⌄**：点击收起键盘；长按展开或收起候选列表
- **⇌**：唤起系统输入法切换器，可直接换到其他输入法且键盘不收起

## 智能联想

| 场景 | 自动增加的候选 |
|---|---|
| 打出沉淀化合物 | `↓` |
| 打出气体 | `↑` |
| 输出单个元素 | 该元素常见离子，如 `Fe` → `Fe²⁺`、`Fe³⁺` |
| 长按上滑 `N` 键 | `⁺`、`⁻` |

## 主题与外观

首页「外观和显示」分区用于调整配色，点「当前主题」条弹出竖排主题列表。

| 主题 | 主色 |
|---|---|
| AgBr | 金黄色 |
| KMnO₄ | 紫色 |
| CuCl₂ | 青色（默认） |
| Fe₂O₃ | 红色 |

「自动」主题跟随系统壁纸取色：Android 12 及以上使用系统调色板，较低版本取壁纸主导色，换壁纸后
会重新取色。「浅色 / 深色」按钮三态循环：浅色 → 深色 → 跟随系统。

## 安装

1. 从 [Releases](../../releases) 下载最新 `JieHuaFa-<版本>.apk` 安装
2. 打开应用，按引导在系统设置中打开「接化发」开关
3. 引导第二步「前往」，在列表中选择「接化发 · 化学输入法」

> 列表里找不到「接化发」？部分系统只列出已启用的输入法。可进入「设置 → 语言与输入法 →
> 当前输入法 / 默认输入法」选择「接化发 · 化学输入法」，选中即同时完成启用与切换。

## 从源码构建（Windows）

构建链不依赖 Gradle：`aapt2 → javac → d8 → 打包 → zipalign → apksigner`。

前置要求：

- JDK 17（`javac` 可用）
- Android SDK：`platforms/android-34` + `build-tools/35.0.0`
- Python 3（`patch_manifest.py`、`zip_insert.py` 需要）

```powershell
cd source
# 先把 build.cmd 顶部的 SDK= / JDK= 改为本机路径
build.cmd
# 输出：source\out\JieHuaFa.apk
```

词库匹配自检（117 条用例）：

```powershell
python source/tools/test_matcher.py
```

> 签名密钥不随仓库分发。请用 `keytool` 自行生成 `source\keystore\debug.jks`，
> 或改动 `build.cmd` 中的 `KEYSTORE` 指向自己的密钥。

## 常见问题

| 问题 | 处理 |
|---|---|
| 已安装但输入框调不出接化发 | 先在系统设置启用，再到「当前输入法 / 默认输入法」中选择 |
| 长时间不用后首次唤起慢 | 部分厂商系统限制输入法后台运行，允许「后台运行 / 自启动」 |
| 找不到某个符号 | 看符号页四个分类；字母键右下角符号可上滑输入，长按查看全部变体 |
| 输入内容会被上传吗 | 不会。拼音匹配与词库都在本机完成，应用无网络权限 |
| 横屏键盘为什么没有全屏 | 当前版本保持内嵌键盘，这是既定行为 |
